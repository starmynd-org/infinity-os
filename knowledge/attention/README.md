# Attention OS: the programme's own record

Created 2026-09-10 by `ATTENTION-OS-admiral`. Two directories, both sole-written by that seat:

- `knowledge/attention/` holds meaning: doctrine for the front door, routing rules, entity
  resolution notes, evaluation cases, the decision packets that were put to the operator and how
  they were answered.
- `_system/attention/` holds contracts and checklists the lanes execute against: receipt
  expectations, the act-door verb set and its reasons, the synthetic fixture labelling rule, the
  linkage fields.

## Why they are in the runtime repo and not in the company brain

The runtime's `CLAUDE.md` says meaning belongs in the company brain, and records one exception:
doctrine lanes must obey lives beside the code, "because a rule lanes do not read is not a rule".
Every author, tester and reviewer this programme launches works in a runtime worktree, so the
files they must obey live here. Placement is recorded in the Admiral's status file
(`Restart Outputs/2026-09-10-r1/status/ATTENTION-OS-admiral.md`, section 1). Promotion into the
company brain (`your-brain`) or into an Attention OS repo of its own is a
later, deliberate move; nothing here is promoted by being written.
