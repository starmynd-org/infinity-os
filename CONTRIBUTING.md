# Contributing

**Outside pull requests are not accepted yet.** Infinity OS is in alpha, and its history on this
repository is published from a private development repository, one release at a time. A pull
request opened here cannot be merged into that flow, so it will be closed.

What helps, and is welcome:

- **Bug reports** through the Bug report issue form: the commit, the command, and the output.
- **Feature requests** through the Feature request issue form: the job you are trying to do, in
  your own words, and how you would know it worked.
- **Security reports** privately, as `SECURITY.md` describes. Never in an issue.

How changes are made: every fix lands with a test that fails before the fix and passes after it,
and every claim in a guide says whether it was measured, read from the code, or inferred. When
outside contributions open, this file will say how to propose a change and what a pull request
must include.
