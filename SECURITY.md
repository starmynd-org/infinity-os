# Security

Please do not report security problems in public issues, discussions or pull requests.

Report privately through GitHub's **Report a vulnerability** button on this repository's
**Security** tab. Only the maintainers can see a private report.

We will acknowledge your report and tell you what we will do next.

Supported versions: while Infinity OS is in alpha, only the newest commit on `main` is supported.

Useful to include: the commit you are on (`git rev-parse --short HEAD`), what you did, what happened,
and whether the console was reachable from anywhere other than `127.0.0.1` on its own server.
Please do not include real credentials, even expired ones.
